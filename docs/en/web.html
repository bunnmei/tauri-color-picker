Use on the web

Color Picker / browser version

Use it right here without installing anything. Picked colors and palettes are saved only in this browser.

  • The screen eyedropper works in Chrome / Edge. In other browsers, pick colors from the color square
  • The eyedropper can also grab colors outside the browser (from other apps)
  • The app's interface is in Japanese — see the guide for translations
