Guide

Color Picker / Windows, macOS, Linux

Pick a color → choose a format → copy. Picked colors appear in the history on the right, and you can drag them onto the palette to keep them.

The app's interface is in Japanese. Labels are translated in this guide.

1. Install

Download the file for your OS from GitHub Releases.

OSFileHow to install
Windows (64-bit)*_x64-setup.exeDouble-click and follow the installer
macOS (Apple Silicon)*_aarch64.dmgOpen it and drag the app into Applications
Debian / Ubuntu*_amd64.debsudo apt install ./file-name.deb
Fedora / openSUSE*.x86_64.rpmsudo dnf install ./file-name.rpm
macOS says the app "is damaged and can't be opened"

The app isn't signed, so macOS blocks it. After moving it to Applications, run this in Terminal:

xattr -cr /Applications/colorPicker.app
Windows shows "Windows protected your PC"

Click "More info" → "Run anyway" to install.

2. Pick a color

Use the bar with the eyedropper icon and the color square on the right side of the window.

  1. Click the color squareYour OS's color dialog opens. Choose a color, or use the dialog's eyedropper to grab one from the screen.
  2. On Linux, click the eyedropper iconThe Linux color dialog has no eyedropper, so the icon picks a color from the screen directly. When the cursor changes, click the spot you want.
  3. It's added to the historyOnce you confirm a color, it's added to the top of the history below. The 6 most recent colors are kept.

3. Copy the color code

Press the copy button at the right of a history row to copy the code shown. Change the format with the two option groups at the bottom right — "カラーコード" (color code) and "文字列としてコピー" (copy as string).

SettingExample of copied text
HEX#598ADE
RGBrgb(89,138,222)
HSLhsl(218,67%,61%)
No quotes#598ADE
Single quotes'#598ADE'

Your settings are remembered after you close the app.

4. Arrange colors on the palette

The palette on the left has 10 small slots and 5 large ones.

  • Place: drag a history swatch (the left end of each row) onto a palette slot
  • Copy: drag a palette color onto another slot
  • Clear: double-click a slot

The palette is saved too, so it's still there the next time you open the app.

When the window is narrow, the palette is hidden and only the history is shown.

5. Theme and palette background

  • Use the switch at the top right to toggle light / dark
  • "パレットの色" (palette color) changes the palette background — handy for checking how colors look on white or black. Switching the theme resets it

6. Troubleshooting

The eyedropper shows an error on Linux

On Linux (especially Wayland) apps can't read the screen directly, so the app asks your desktop's xdg-desktop-portal for the color. Make sure xdg-desktop-portal-kde (KDE) or xdg-desktop-portal-gnome (GNOME) is installed.

On Linux the window is blank or the app crashes on launch

A workaround for NVIDIA drivers on Wayland is already built in. If it still happens, try launching it like this:

WEBKIT_DISABLE_COMPOSITING_MODE=1 color-picker
Colors I hover over while dragging aren't added to the history?

Right — a color is added only when you confirm it in the dialog, so the history isn't flooded while you drag.
