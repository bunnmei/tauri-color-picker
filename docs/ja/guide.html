Color Picker ／ Windows・macOS・Linux

色を取る → 形式を選ぶ → コピー。取った色は右側の履歴に並び、ドラッグ&ドロップでパレットに保存できます。

1. インストール

GitHub の Releases から、使っている OS に合ったファイルをダウンロードします。

OSファイルインストール
Windows（64bit）*_x64-setup.exeダブルクリックしてインストーラーの指示に従う
macOS（Apple Silicon）*_aarch64.dmg開いて、アプリを「アプリケーション」フォルダへドラッグ
Debian / Ubuntu*_amd64.debsudo apt install ./ファイル名.deb
Fedora / openSUSE*.x86_64.rpmsudo dnf install ./ファイル名.rpm
macOS で「壊れているため開けません」と出るとき

署名していないアプリのため、macOS がブロックしています。アプリを「アプリケーション」に移したあと、ターミナルで次を実行してください。

xattr -cr /Applications/colorPicker.app
Windows で「PC が保護されました」と出るとき

「詳細情報」→「実行」を押すとインストールできます。

2. 色を取る

画面右側の、スポイトのアイコンと色の四角が並んだボタンから色を取ります。

  1. 色の四角をクリックするOS の色選択ダイアログが開きます。好きな色を選ぶか、ダイアログのスポイトで画面上の色を取ります。
  2. Linux ではスポイトのアイコンをクリックするLinux の色選択ダイアログにはスポイトが無いため、アイコンから直接画面の色を取れるようにしています。カーソルが変わったら、取りたい場所をクリックします。
  3. 履歴に追加される色を確定すると、その下の履歴の一番上に追加されます。履歴は新しい順に 6 件まで残ります。

3. カラーコードをコピーする

履歴の各行の右にあるコピーボタンを押すと、表示されているカラーコードがクリップボードに入ります。表示の形式は画面下の「カラーコード」と「文字列としてコピー」で切り替えます。

設定コピーされる文字列の例
HEX#598ADE
RGBrgb(89,138,222)
HSLhsl(218,67%,61%)
クォートなし#598ADE
シングルクォート'#598ADE'
ダブルクォート"#598ADE"

設定はアプリを閉じても覚えています。

4. パレットに並べる

左側のパレットには、小さい枠 10 個と大きい枠 5 個があります。

  • 置く：履歴の色見本（各行の左端）を、パレットの枠へドラッグ&ドロップします
  • コピーする：パレットの色を、別の枠へドラッグ&ドロップします
  • 消す：枠をダブルクリックします

パレットの中身も保存されるので、次に開いたときもそのまま残っています。

ウィンドウの幅を狭くすると、パレットは隠れて履歴だけの表示になります。

5. テーマとパレットの背景色

  • 右上のスイッチでライト / ダークを切り替えます
  • 「パレットの色」で、パレットの背景色を変えられます。白い背景・黒い背景の上で配色がどう見えるか確かめるのに使えます。テーマを切り替えると元の色に戻ります

6. 困ったときは

Linux でスポイトを押してもエラーになる

Linux（特に Wayland）では、アプリが画面を直接読めないため、デスクトップ環境の「xdg-desktop-portal」に色の取得を頼んでいます。KDE なら xdg-desktop-portal-kde、GNOME なら xdg-desktop-portal-gnome が入っているか確認してください。

Linux で画面が真っ白になる・起動直後に落ちる

NVIDIA のドライバーと Wayland の組み合わせで起きる問題への対策は組み込み済みです。それでも直らないときは、次のように起動してみてください。

WEBKIT_DISABLE_COMPOSITING_MODE=1 color-picker
色の四角を動かしている途中の色は履歴に入らない？

はい。ダイアログで色を確定したときだけ履歴に追加します。ドラッグ中の色で履歴が埋まらないようにするためです。

不具合を見つけた・要望がある

GitHub の Issues から教えてください。
