Color Picker
ホーム 使い方
English

画面の色を、
そのままコードに。

ほかのアプリやブラウザの上にある色もスポイトで取得。
HEX・RGB・HSL を選んで、ワンクリックでコピーできます。

ダウンロード 使い方を見る GitHub

特徴

アプリをまたいで色を取得

スポイトで画面上のどこでもクリックするだけ。デザインツールやブラウザの色もそのまま拾えます。

HEX / RGB / HSL でコピー

形式と、クォート（' / "）の有無を選べるので、CSS やコードにそのまま貼れます。

履歴とパレット

取得した色は直近 6 件が残ります。ドラッグ&ドロップでパレットに並べて、配色をまとめておけます。

ライト / ダーク

ボタンひとつでテーマを切り替え。パレットの背景色も変えられるので、実際の背景で配色を確かめられます。

動作環境

OSダウンロードするファイル
Windows（64bit）*_x64-setup.exe
macOS（Apple Silicon）*_aarch64.dmg
Debian / Ubuntu*_amd64.deb
Fedora / openSUSE*.x86_64.rpm

ファイルは GitHub の Releases にあります。インストールの注意点は使い方を見てください。

データは外に出ません

取得した色やパレットはこの PC の中だけに保存されます。通信も、アカウント登録も、解析ツールもありません。
